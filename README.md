# Ambient Source Events

OBS Studio用Luaスクリプト「ソース定期表示」です。

現在のバージョン：0.7.0

画像・テキスト・Browser Source・Media Sourceなどのソースを、一定間隔またはランダムな間隔で自動表示します。配信中の告知、SNS案内、画像、GIF、動画などを、手動操作なしで定期的に表示する用途を想定しています。

## 主な機能

- 固定間隔／ランダム間隔で自動表示
- 初回にすぐ表示／最初の待機後に表示
- 開始・終了エフェクトを個別に設定
- Fade、Peek、Wipe、Wipe Softness、Zoom
- Linear、Cubic Ease In、Ease Out、Ease In-Out
- Media Sourceをイベントごとに先頭から再生
- 完全非表示中の対象ソースをミュート
- フィルター無効化・削除時に表示・音声・再生状態を復元

## 導入方法

1. [ambient-source-events.lua](ambient-source-events.lua)を入手し、移動せず使える場所へ置きます。
2. OBS Studioの「ツール」→「スクリプト」を開きます。
3. 「＋」から`ambient-source-events.lua`を追加します。
4. 自動表示したいソースの「フィルタ」を開きます。
5. 映像のエフェクトフィルタの「＋」から「ソース定期表示」を追加します。
6. 間隔、表示時間、開始／終了エフェクトを設定します。

追加のOBSプラグインや外部シェーダーファイルは必要ありません。

## 基本的な使い方

- 「固定間隔」または「ランダム間隔」を選びます。
- 必要に応じて、初回にすぐ表示するか、最初の待機後に表示するかを選びます。
- 画像・テキスト・Browser Sourceなどでは「表示時間」を設定します。
- 開始と終了には、それぞれ「なし」「フェード」「Peek」「Wipe」「Zoom」を設定できます。
- Wipeでは境界のSoftness、Zoomでは基準点と倍率を設定できます。

## Media Sourceを使う場合

標準Media Sourceのプロパティで、次の3項目を**OFF**にしてください。

- 「繰り返し」
- 「ソースがアクティブになったときに再生を再開する」
- 「非アクティブ時にファイルを閉じる」

条件が一致しない間はイベントを開始せず、ソースを非表示・ミュートにします。本スクリプトの使用中は、ほかの自動再生スクリプト、ホットキー、手動シークなどによる再生操作を併用しないでください。

## 重要な注意事項

- 完全非表示中は、対象ソースをミュートします。
- ミュートや再生制御は、同じソースを参照しているすべてのシーンに影響します。
- 同じソースへ「ソース定期表示」を複数追加することはできません。
- Zoomは開発者環境で5,000%まで動作確認済みです。それ以上も設定できますが、環境やソースによっては正常に描画できない場合があります。

## 主な制限

- 複数エフェクトを同時に組み合わせる機能はありません。
- Image Sourceとして読み込んだGIFやBrowser内のアニメーションは、非表示中も内部の進行が続きます。イベントごとにGIFを先頭から再生する場合は、標準Media Sourceを使用してください。
- VLCやネットワーク配信などは、Media Sourceの再生制御対象外です。
